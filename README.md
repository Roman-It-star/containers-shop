# ContainerMarket — сайт по продаже контейнеров


Учебный проект по HTML5/CSS3/JavaScript на тему **«Продажа контейнеров»**.  
Сайт разработан для зачётного задания и демонстрирует использование новых возможностей HTML5, CSS3 и Web Storage в соответствии с пособием по курсу.

**Реализация требований зачётного задания:**
**1.1. Семантическая разметка HTML5 (не менее 5 элементов)**
Где смотреть:
index.html — пример полной семантической структуры страницы.
catalog.html, contacts.html — использование <section>, <article>, <aside>.
**1.2. Новые возможности CSS3 (не менее 5 правил)**
Где смотреть:
css/styles.css — все перечисленные свойства присутствуют в одном файле и применяются к различным элементам разметки.
**1.3. Новые элементы управления форм HTML5 (не менее 5 элементов)**
Где смотреть:
order.html — форма с полями разных типов и новыми атрибутами.
**1.4. WebStorage (localStorage)**
Где смотреть:
order.html — форма заказа, к которой привязан сценарий.
js/main.js — функция isSupportLocalStorage() и работа с localStorage (getItem, setItem).
**1.5. SVG / Canvas API**
Где смотреть:
scheme.html — блок с <svg> внутри <section class="scheme-wrapper">.
